# App Review Information — posing 1.0

Values and notes for App Store Connect (ASC) → App Review Information.

## App Review Information values

| Field | Value |
| --- | --- |
| Sign-in required | **No** |
| Demo account username | Leave blank |
| Demo account password | Leave blank |
| Contact information | Provide a monitored contact who can respond to Apple |
| Notes | Paste the English block below |

## Review Notes (EN)

```text
Thank you for reviewing posing.

All features in this release are free. No account or sign-in is required.
There are no subscriptions or in-app purchases.

WHAT TO TEST
1. Browse and search the Community pose library.
2. Open a pose and use its guide with the camera.
3. Create a pose guide from a photo when prompted.
4. Capture photos and review them in the on-device gallery.

CAMERA / PHOTOS
Camera and photo-library access are requested only when you use those features.
The app can be opened and reviewed without granting either permission.

PRIVACY
Privacy Policy: https://sites.google.com/view/posingapp/privacy-policy
```

## Submission checklist

- [ ] Set **Sign-in required** to **No**.
- [ ] Leave demo username and password blank; do not provide account credentials.
- [ ] Confirm the submitted build has no paid feature gate or purchase flow.
- [ ] Confirm the Notes match the submitted build and its available screens.
- [ ] Confirm the Privacy Policy URL is public and opens without sign-in.
- [ ] Provide accurate reviewer contact information that is monitored.
