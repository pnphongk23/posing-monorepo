# App Store Publish — Asset & Metadata Package

Bộ hồ sơ metadata, nội dung pháp lý và hướng dẫn chuẩn bị phát hành App Store cho ứng dụng **posing** (`posing.camera.app`).

- **Legal URLs:** [Terms of Service](https://sites.google.com/view/posingapp/terms-of-service) · [Privacy Policy](https://sites.google.com/view/posingapp/privacy-policy)
- **Firebase iOS App:** Đã cấu hình cho `posing.camera.app` (project `camerapose-a0877`).

## Các file trong package

| File | Nội dung |
| --- | --- |
| [app-store-metadata.md](./app-store-metadata.md) | Name, subtitle, description EN, keywords, what's-new, category + bản phụ lục VI |
| [privacy-support.md](./privacy-support.md) | Privacy Policy, App Privacy nutrition labels, Support URL |
| [screenshots-runbook.md](./screenshots-runbook.md) | Kích thước, màn hình cần chụp, checklist và quy trình upload |
| [app-icon-check.md](./app-icon-check.md) | Bảng kiểm tra kỹ thuật và visual checklist cho App Icon (1024×1024) |
| [app-store-checklist.md](./app-store-checklist.md) | Checklist tổng hợp các hạng mục App Store Connect |
| [app-review-notes.md](./app-review-notes.md) | Thông tin App Review: demo account, review notes EN, checklist kiểm tra |

## Nguyên tắc & quy định

1. **Copy phải đúng với app thật**: Không mô tả tính năng chưa có. Subscription/paywall đã tích hợp và bắt buộc kèm link Terms of Use (EULA) + Privacy Policy trong Description (Guideline 3.1.2).
2. **Ngôn ngữ phát hành**: English (US) là ngôn ngữ chính; bản Tiếng Việt sẵn sàng làm phụ lục.
3. **Category**: `Lifestyle` (Primary) + `Photo & Video` (Secondary).
4. **Legal URLs**:
   - Terms: `https://sites.google.com/view/posingapp/terms-of-service`
   - Privacy: `https://sites.google.com/view/posingapp/privacy-policy`
